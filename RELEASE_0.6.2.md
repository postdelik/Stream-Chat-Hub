# Stream Chat Hub 0.6.2

Последнее служебное обновление Stream Chat Hub.

Эта версия добавляет безопасный переход на Wyrmo Chat:

- перед переходом показывается отдельное предупреждение;
- пользователь явно выбирает, согласен ли он на новую систему лицензий;
- при согласии загружается Wyrmo Chat с официального сайта `wyrmo.ru`;
- при отказе текущая версия Stream Chat Hub остаётся без изменений;
- повторно открыть предложение можно ручной проверкой обновлений.

Важно: после перехода одна лицензия Wyrmo работает на одном компьютере.
