# Stream Chat Hub

## English

Stream Chat Hub is a desktop application for reading Twitch chat and displaying it as a customizable OBS overlay.

The app is currently focused on Twitch. YouTube and other platforms may be added later.

### Current Features

- Twitch chat connection
- Public Twitch chat reading without login
- Twitch Login support
- Viewer counter for connected Twitch channels
- Unified chat window inside the app
- OBS Browser Source overlay
- Custom overlay size and position
- Overlay presets
- Message appearance settings
- Color background mode
- Shared chat bubble mode
- Separate bubble per message mode
- Custom PNG, WebP, GIF, MP4, WebM, MOV overlay style upload
- Optional style preview inside the app
- Font selection for messages
- Message filters
- Overlay test mode with fake messages
- Russian and English interface
- Portable Windows build

## Development

Install dependencies:

```bash
npm install
```

Run in development mode:

```bash
npm run dev
```

Build:

```bash
npm run build
```

Create distributable package:

```bash
npm run dist
```

## Русский

Stream Chat Hub — desktop-приложение для чтения Twitch-чата и отображения его в виде настраиваемого OBS overlay.

Сейчас приложение сфокусировано на Twitch. Поддержка YouTube и других платформ может появиться позже.

### Текущие возможности

- Подключение Twitch-чата
- Чтение публичного Twitch-чата без логина
- Поддержка Twitch Login
- Счётчик зрителей для подключённых Twitch-каналов
- Единое окно чата внутри приложения
- OBS Browser Source overlay
- Настройка размеров и позиции overlay
- Overlay presets
- Настройки внешнего вида сообщений
- Режим цветного фона
- Режим общего бабла
- Режим отдельных баблов сообщений
- Загрузка своих PNG, WebP, GIF, MP4, WebM, MOV стилей overlay
- Опциональный показ стиля внутри приложения
- Выбор шрифта сообщений
- Фильтры сообщений
- Тестовый overlay режим с фейковыми сообщениями
- Русский и английский интерфейс
- Portable Windows build
